## Cross-Grant Strategy

```
DIV Fund (2026)                 → Fund platform development + pilot deployment
         ↓
Epic MegaGrants (Sept 2026)     → Build the UE + AI creator platform
         ↓
ISIF Asia (2027)                → Expand distribution, offline access, creator training
         ↓
PCF / GIF / UNESCO              → Educational validation, language models, scaling
```

**Synergy principle:** Each grant builds on the previous one. DIV Fund funds the build, Epic provides the engine, ISIF expands the reach, follow-on grants validate the impact and scale.
