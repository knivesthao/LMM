# Pre-Submission Checklist

> Run through this before submitting any grant.

## Content

- [ ] Problem statement is compelling and specific
- [ ] Solution is clearly described and matches the problem
- [ ] Innovation is clearly differentiated from competitors
- [ ] Budget is realistic and justified with notes
- [ ] Timeline is achievable and milestones are concrete
- [ ] Sustainability plan is credible
- [ ] All statistics are sourced

## Formatting

- [ ] Within page/word limits
- [ ] No placeholder text (X, TBD, TODO)
- [ ] Consistent markdown formatting
- [ ] Spell-checked
- [ ] Read by someone unfamiliar with the project

## Grant-Specific

- [ ] Meets all eligibility criteria
- [ ] Follows their template (if required)
- [ ] Submitted before deadline
- [ ] All required attachments included
